# License Policy

HDEC-LIC-001 establishes the licensing baseline for material that OSHEThai has
the right to license.

- Software, engineering documentation, Agent Controls, and repository
  artifacts default to [MPL-2.0](LICENSE).
- A public contract, public schema, SDK, integration example, or conformance
  kit uses Apache-2.0 only when an explicit `RIGHTS-METADATA.json` rule declares
  that public scope.
- Every file must match validated rights metadata. Missing or unknown rights
  fail closed.
- Contributions are inbound-equals-outbound and require DCO 1.1 sign-off. No
  CLA or commercial dual license is used.
- Standard license text must remain unmodified. Do not add industry, trade, or
  safety-use restrictions.

Third-party text and assets retain their original rights. Customer/company
overlays and OSHE names, logos, marks, and official-status indicators are not
granted by this policy.
