### 3.3 Directory Visibility and Anti-Enumeration Rules (`H030-005`)

1. **Exact-Scope Filtering Invariant:** Directory queries (`ListUsers`, `SearchDirectory`) resolve caller scope strictly from authenticated session claims. If a user is assigned to `prj_alpha`, query results are partitioned exclusively to `prj_alpha`. Cross-project, cross-business-unit, or cross-tenant discovery returns an empty list (`[]`) with HTTP 200 to prevent existence oracle leaks.
2. **Anti-Enumeration Pagination:** Directory endpoints require bounded limit-offset or cursor pagination (maximum limit $\le 50$ records per request). Arbitrary bulk dumps (`limit=ALL`) fail closed with HTTP 400.
3. **Response Field Minimization:** Directory response envelopes return only `subject_id`, `display_name`, and assigned `role_code`. Personal email addresses, creation timestamps, and phone numbers are excluded from general directory responses.

The negative controls below must be implemented in test suites and must pass with verified denial outcomes prior to milestone review.

## 6. Unsupported-Profile Catalog and Explicit Exclusions

To eliminate ambiguity and prevent unplanned architecture drift, the following runtimes, services, protocols, and data types are explicitly declared as **UNSUPPORTED** for Milestone v0.3.0. Any attempt to implement, configure, or rely upon these capabilities constitutes a violation of milestone scope:

### 6.1 Unsupported Identity Providers and Runtimes
1. **Enterprise Identity Providers (OIDC / SAML 2.0):** Integration with Okta, Microsoft Entra ID (Azure AD), Google Workspace, PingIdentity, or Keycloak is unsupported.
2. **Social Identity Providers:** Authentication via Google Sign-In, Apple ID, Facebook, or LINE Login is unsupported.
3. **Public Key Infrastructure (PKI) Client Certificates:** Mutual TLS (mTLS) client certificate authentication for end-users is unsupported.
4. **Offline Refresh Tokens & Biometric Keystores:** Refresh tokens with multi-month lifetimes, WebAuthn/FIDO2 hardware keys, and biometric mobile keystores are unsupported.

### 6.2 Unsupported Client Platforms & Synchronization Engines
1. **Native Mobile Applications:** Native iOS (Swift/SwiftUI) and native Android (Kotlin/Compose) application binaries are unsupported.
2. **Cross-Platform Mobile Frameworks:** Flutter, React Native, or Xamarin mobile wrappers are unsupported.
3. **Mobile Edge Synchronization Daemon:** Background SQLite delta synchronization, peer-to-peer mesh synchronization, and offline conflict resolution daemons are unsupported (deferred to v0.4.0).
4. **Legacy Web Browsers:** Internet Explorer (all versions), legacy Microsoft Edge (pre-Chromium), and Safari versions prior to 17 are unsupported.

### 6.3 Unsupported Infrastructure and Hosting Topologies
1. **Public Cloud Multi-Node Hosting:** Deployment to AWS, Google Cloud, Microsoft Azure, or public Kubernetes (EKS/GKE/AKS) clusters is unsupported (`H030-008 HOLD`).
2. **Public Content Delivery Networks (CDNs):** CDN edge caching via Cloudflare, Fastly, AWS CloudFront, or Akamai is unsupported (`H030-007 HOLD`).
3. **Public DNS and Public IP Routing:** Public domain registration, external DNS mapping, and public ingress reverse proxy configurations are unsupported (`H030-007 HOLD`).
4. **Distributed Object Stores:** Commercial AWS S3 with KMS, multi-datacenter MinIO, or Google Cloud Storage are unsupported; local SeaweedFS container is used exclusively.

### 6.4 Unsupported Data Classifications and Business Operations
1. **Real Customer and Production Data:** Ingestion, staging, or migration of live customer data, real worker personal records, or production database snapshots is unsupported (`H030-005`).
2. **Clinical and Medical Health Records:** Ingestion of medical examination reports, biometric health scans, or clinical surveillance files is unsupported (`V020-D05`).
3. **Automated Cross-Tenant Analytics & AI Inference:** Cross-tenant aggregation, external machine learning API calls, automated risk scoring, or generative AI decision-making are unsupported.
4. **Hard Deletion / Physical Record Purging:** Physical SQL `DROP TABLE`, `TRUNCATE`, or `DELETE` operations on operational entities and audit journals are unsupported (`H030-002`).
